# Basketball Scoreboard
## What it does?
This is a simple HTML, CSS and JavaScript Website, which displays a Basketball Scoreboard,
where you can add 1, 2 or 3 point to whether the Home or Guest Team.
There is also a Reset Button to start at 0 for both Teams.

## Setup
You can simply clone the repo and then double-click the index.html File 
so that it oppens in a Browser of your choice. The index.css and index.js are automatically
linked to the HTML-File so you don't have to worry about that
